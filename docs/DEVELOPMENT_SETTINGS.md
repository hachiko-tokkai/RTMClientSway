# 開発版の設定

対象は `1.1.1` です。「Mods → RTM Client Sway → Config」、または `config/rtmclientsway.cfg` で調整します。設定は全車両共通です。

| 項目 | 効果 | 初期値 |
|---|---|---|
| enabled | 動揺全体のON/OFF | ON |
| strength | 合成後の揺れ全体の倍率 | 1 |
| running | 走行中の左右・上下・ロールの強さ | 1 |
| curve | 曲線の持続外傾と進入・退出の揺れ | 1 |
| switch | トング・クロッシングの横・上下衝撃 | 1 |
| stop | 急制動・停止時のピッチと前後変位 | 1 |
| vertical | 走行・分岐の上下動 | ON |
| pivotHeight | 回転中心の高さ（m） | 1.5 |

各倍率は0でその効果を無効にできます。全体倍率と効果別倍率は乗算されるため、強くする場合は片方ずつ調整してください。初期値を基準に、直線、左右カーブ、前後方向の分岐、弱い制動と強い制動の停止を確認します。

旧cfgの同名項目は引き継がれます。設定画面で保存すると、車両の動揺状態が再生成されます。
